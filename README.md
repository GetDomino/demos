# Domino demos

Apps a coding agent built with [Domino](https://domino.run) from one prompt. Each folder holds the app's source, the exact prompt (`PROMPT.md`) and the campaign record the agent kept (`CAMPAIGN.md`).

| Demo | What it does |
| --- | --- |
| [devcon-booth](devcon-booth/) | A booth selfie quest: a selfie with the Domino sign in it earns 100 points, and a photo someone already used goes to staff. |

To build your own, paste this prompt into your coding agent:

```text
https://console.domino.run/docs/try-with-your-agent.txt
```
